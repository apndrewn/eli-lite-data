# eli-lite-data

Published tools for **ELI for Harvey**: ELI's program tools (no AI) that complement Harvey.

- Built from the same code as ELI (apndrewn/eli-data); this repo holds only the tools ELI for Harvey loads, its tool list (`tools-manifest-v3.json`) and an empty `admin-overrides.json`.
- Build Draft templates and email rules are read from apndrewn/eli-data, the same library ELI uses.
- `snippet/` holds the Script Lab snippet and the script that makes it from the published ELI snippet. The snippet keeps its settings and installed tools separate from ELI's.
Script Lab import URL: https://gist.githubusercontent.com/apndrewn/d396713727a76a86ed2e1ef690b333fe/raw/
